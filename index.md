# Manoa Maintenance

## Overview

Manoa Maintenance aims to help students at the University of Hawaiʻi at Mānoa stay informed about broken or damaged facilities around campus.

Students may encounter broken water fountains, vending machines, bathrooms, sidewalks, and other campus facilities without knowing whether these problems have already been reported.

Our application provides a centralized platform where students can report maintenance issues, browse reports submitted by others, check their statuses, and favorite issues they want to follow.

Each student will have a personalized dashboard displaying their submitted and favorited reports, including the current status and how long each issue has been active.

Administrators will be able to review reports, remove spam submissions, and update maintenance statuses.

### Browse Page

The Browse Page displays existing maintenance reports submitted by other students.

Users can filter reports by location and maintenance status to find relevant issues.

This helps students determine whether a problem has already been reported instead of creating a duplicate report.

### Submit a Report Page

The Submit a Report Page allows logged-in students to report broken or damaged campus facilities.

Each report can include:

- Location of the issue
- Description of the problem
- Possible alternative solutions
- Photo of the issue

After submission, the report will appear on the Browse Page and the user's dashboard.

### Report Details Page

The Report Details Page displays information about a specific maintenance issue.

Information includes the location, description, photo, date submitted, and current status.

Students can favorite reports they want to follow and mark issues as fixed when a problem has been resolved.
